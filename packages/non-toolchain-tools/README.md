# `@computerwwwizard/non-toolchain-tools`

This package houses development tools and guardrails that are not required in CI/CD build environments, offloading non-toolchain dependencies to streamline pipeline executions while remaining available for developers and AI agents.

For full architecture details and decision context, see the [Non-toolchain Tools Installation ADR](../../docs/adr/non-toolchain-tools/installation.md).
